## 几个常见疑问

**静态住宅IP和动态住宅IP到底选哪个？**

静态IP长期固定，适合需要稳定登录环境的业务（TikTok养号、电商店铺、长期社媒运营）。动态IP会变，适合数据采集、广告验证、SEO监测这种需要大量不同IP但不需要长期固定的场景。丽萨主机主要做静态住宅IP，动态住宅IP需要的话看它家的动态IP系列或第三方代理服务。

**住宅IP VPS 和普通代理IP有什么区别？**

代理IP只是转发流量，你本地还是用自己IP出口，只是经过代理中转。VPS是完整的一台虚拟服务器，你有root权限，可以装任何软件、跑任何服务，IP是这台服务器的真实出口。做TikTok直播、跑自动化脚本、需要长期挂机的情况下，VPS比代理更合适。

**48小时退款是真的吗？**

大部分套餐支持48小时不满意无条件退款，但表格里标注"特殊产品，仅退网站余额"的VDS套餐例外——这些套餐退款只能退到网站余额，不能提现。下单前看清楚套餐说明里的退款规则。

**IP会被封吗？**

任何IP都有被风控的可能，住宅IP只是降低概率，不是绝对安全。丽萨主机的住宅IP段相对纯净，但如果同一个IP被多人共用过（比如之前的用户做过违规操作），仍可能被平台标记。遇到IP问题可以提交工单申请更换，客服一般会处理。
